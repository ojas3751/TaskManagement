# 画面設計 v1.1

**関連文書**: [要件定義書](../requirements.md) ／ [機能仕様書](../functional-spec.md) ／ [文書一覧](../README.md)

**画面はボード画面1つのみ。** 認証を対象外としたため、ログイン画面は存在しない。

本書の図は**ワイヤーフレーム相当**であり、**要素の有無と配置を示すもの**。寸法・余白・書体・具体的な配色は含まない（[要件定義書](../requirements.md) の「未決定事項」のとおり未定）。

> **本書では「タスク」と書く。** DBのテーブル名とAPIのパスは `cards` のままであり、これは意図的な使い分け（[要件定義書](../requirements.md) の「用語」を参照）。
>
> **画面は開発段階によって2つの形をとる。** F-12（移動ボタン）は F-13（ドラッグ&ドロップ）の実装をもって廃止されるため、1章に Step 8〜10 の画面、1.5章に **F-13 実装後の完成形**を示す。

## 1. ボード画面（Step 8〜10：移動ボタンがある段階）

```
┌──────────────────────────────────────────────────────────────────────┐
│  マイタスク                                                           │
├──────────────┬──────────────┬──────────────┬────────────────────────┤
│ [←] TODO [→] │ [←] 進行中[→]│ [←] 設計 [→] │ 完了                   │
│              │              │   [改名][削除]│                        │
│              │              │              │ [☐ すべて選択]         │
│ [+ タスク追加]│ [+ タスク追加]│ [+ タスク追加]│ [+ タスク追加]         │

│ ┃[↑][↓][←][→]┃ │ │[↑][↓][←][→]│              │  └───────────────────┘│
│ ┃       [削除]┃ │ │     [削除] │              │ ☐┌───────────────────┐│
│ ┗━━━━━━━━━━┛ │ └──────────┘ │              │  │ 見積提出           ││

│ ┃ 買い物      ┃ │              │              │  └───────────────────┘│
│ ┃ 08/16      ┃ │              │              │      ：（9件目まで）   │
│ ┃[↑][↓][←][→]┃ │              │              │  ┌───────────────────┐│
│ ┃       [削除]┃ │              │              │  │ 10件目（上部のみ）  ││
│ ┗━━━━━━━━━━┛ │              │              │  ┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈┈ │
│              │              │              │      [∨ もっと見る]    │
│              │              │              │ [選択したものを削除]    │
└──────────────┴──────────────┴──────────────┴────────────────────────┘
                                        [+ リスト追加]
                                     （「完了」の左隣に挿入される）
```

| 要素 | 補足 |
| --- | --- |
| `[←] [→]`（列見出し） | 列の並び替え（F-05）。「完了」には表示しない。**F-13 実装後も残す**（代替手段の F-21 が MVP に無いため） |
| `[改名] [削除]` | **追加した列にのみ表示**。デフォルト3列には出さない（F-03, F-04） |
| **`[+ タスク追加]`** | **列の最上部。** 押して入力すると、**すぐ下（列の先頭）**にタスクが入る（F-06）。「完了」列では `[☐ すべて選択]` の下 |
| `[↑][↓][←][→]`（タスク） | タスクの移動（F-12）。端では無効表示。**F-13 実装時に廃止する**（1.5章を参照） |
| **完了列のタスクの `[↑][↓][←]`** | **差し戻しのため、完了列のタスクにも移動ボタンを表示する**（UC-03）。「完了」は最右のため `[→]` は常に無効 |
| `☐` チェックボックス | **「完了」列のタスクにのみ表示**（F-15） |
| `[☐ すべて選択]` | 「完了」列の見出し直下 |
| （タスクなし） | **空状態。** タスクが0件の列に表示する |
| `：` | 図の省略記号（実際の画面には表示しない） |
| 10件目 | 上部だけが覗く高さで切れる（F-14） |

> **`[+ タスク追加]` を最上部に置く理由。** 追加ボタンが上端にあるのに追加物が末尾に現れると、追加したものが視界の外に出る。9件を超える列ではスクロールしないと確認できず、登録できたか分からない。**操作した位置と、結果が現れる位置を一致させる。**

## 1.5 ボード画面（Step 11 以降：完成形）

**F-13（ドラッグ&ドロップ）の実装をもって、移動ボタンを画面から取り除く。** タスクの移動はドラッグのみになる。

```
┌──────────────────────────────────────────────────────────────────────┐
│  マイタスク                                                           │
├──────────────┬──────────────┬──────────────┬────────────────────────┤
│ [←] TODO [→] │ [←] 進行中[→]│ [←] 設計 [→] │ 完了                   │
│              │              │   [改名][削除]│                        │
│              │              │              │ [☐ すべて選択]         │
│ [+ タスク追加]│ [+ タスク追加]│ [+ タスク追加]│ [+ タスク追加]         │
│ ┏━━━━━━━━━━┓ │ ┌──────────┐ │              │ ☐┌───────────────────┐│
│ ┃ 請求書送付 ┃ │ │ 資料作成  │ │              │  │ 打合せ    08/01    ││
│ ┃ 08/10 09:00┃ │ │ 08/15    │ │ （タスクなし）│  └───────────────────┘│
│ ┗━━━━━━━━━━┛ │ └──────────┘ │              │ ☐┌───────────────────┐│
│ ┏━━━━━━━━━━┓ │              │              │  │ 見積提出           ││
│ ┃ 買い物      ┃ │              │              │  └───────────────────┘│
│ ┃ 08/16      ┃ │              │              │      ：（9件目まで）   │
│ ┗━━━━━━━━━━┛ │              │              │      [∨ もっと見る]    │
│              │              │              │ [選択したものを削除]    │
└──────────────┴──────────────┴──────────────┴────────────────────────┘
```

**同じ件数でも縦に収まる数が増える。** これが移動ボタンを廃止する目的（[機能仕様書](../functional-spec.md) の「タスクの移動・並び替え」を参照）。

| 変更点 | 内容 |
| --- | --- |
| 移動ボタン | **削除。** ドラッグ&ドロップに置き換わる |
| 「完了」列からの差し戻し | **ドラッグのみ**になる。F-13 は「完了」列を移動元・移動先の両方向で扱えることが必須 |
| `[削除]` ボタン | **図では省略している。出し方は未決定**（常時表示・ホバー時のみ・詳細モーダル内へ移動）。移動ボタンを消しても削除ボタンが常時表示のままでは閲覧性の問題が半分しか解決しないため、Step 11 で実物を見て決める |
| チェックボックス、列の `[← →]` | **変更なし。** 引き続き表示する |

## 3. タスクの詳細モーダル（F-07）

タスクのタイトル部分をクリックすると開く。

```
      ┌────────────────────────────────────────────┐
      │ タスクの詳細                          [ ✕ ] │
      ├────────────────────────────────────────────┤
      │ タイトル                                    │
      │ ┌────────────────────────────────────────┐ │
      │ │ 請求書送付                              │ │
      │ └────────────────────────────────────────┘ │
      │                                      5/100 │  ← 文字数カウンタ
      │                                            │
      │ 説明文                                      │
      │ ┌────────────────────────────────────────┐ │
      │ │ 8月分の請求書をまとめて送付する。        │ │
      │ │                                        │ │  ← 改行を保持
      │ │ ・A社                                   │ │
      │ │ ・B社                                   │ │
      │ │                                        │ │
      │ └────────────────────────────────────────┘ │
      │                                   348/5000 │
      │                                            │
      │ 期限                                        │
      │ ┌──────────────┐  ┌──────────┐            │
      │ │ 2026/08/10   │  │  09:00   │            │
      │ └──────────────┘  └──────────┘            │
      │ [ 期限をクリア ]   ☑ 時刻を指定する         │
      │                                            │
      ├────────────────────────────────────────────┤
      │                    [ キャンセル ] [ 保存 ] │
      └────────────────────────────────────────────┘
```

| 要素 | 補足 |
| --- | --- |
| 文字数カウンタ | 入力欄の右下。上限到達で赤 |
| `☑ 時刻を指定する` | **`cards.has_due_time` に対応。** 外すと時分の入力欄が無効になり、表示からも時分が消える |
| `[ 期限をクリア ]` | `due_at` を NULL に戻す（期限なし） |
| 閉じ方 | `[ ✕ ]`、`[ キャンセル ]`、背景クリックのいずれか |

## 4. エラー時の表示

挙動の定義は [機能仕様書](../functional-spec.md) の「誤操作・エラーへの対策」を参照。

### 4.1 初期読み込みに失敗した場合

ボードを表示できないため、全面にエラーを出す。

```
┌───────────────────────────────────────────────────────────────────┐
│  マイタスク                                                        │
├───────────────────────────────────────────────────────────────────┤
│                                                                   │
│                              ⚠                                    │
│                                                                   │
│                 サーバーが起動していません。                        │
│              起動してから再読み込みしてください。                    │
│                                                                   │
│                        [ 再読み込み ]                              │
│                                                                   │
└───────────────────────────────────────────────────────────────────┘
```

### 4.2 操作中に失敗した場合

ボードは表示されたまま、画面上部にメッセージを出す。**あわせて画面の表示を操作前の状態に戻す**（ロールバック）。

```
┌───────────────────────────────────────────────────────────────────┐
│ ⚠ データベースに接続できません。                            [ ✕ ] │
│   Docker が起動しているか確認してください。                        │
├───────────────────────────────────────────────────────────────────┤
│  マイタスク                                                        │
├──────────────┬──────────────┬──────────────┬─────────────────────┤
│ [←] TODO [→] │ [←] 進行中[→]│ [←] 設計 [→] │ 完了                │
│              （ボードはそのまま表示され、操作を続けられる）          │
└──────────────┴──────────────┴──────────────┴─────────────────────┘
```
